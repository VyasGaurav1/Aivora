# Spoken due-task selection

When multiple saved actions are due, present chronological numbered task choices through the existing three-per-page readback. `choose task number two` selects a snapshot; it never executes it. Selection has a fresh opaque token, a monotonic two-minute deadline and one-use consumption. Preserve ID and dueAt from the presented snapshot. Scheduler checks that exact occurrence before preparing review; normal registry checks follow. Do not bind a number to a newly refreshed or sorted list. New commands/cancel replace/clear pending choices. Existing source-bound VoiceChoiceGate remains required for voice replies. Physical speech acceptance remains separate.

Implementation: DueTaskChoices owns immutable chronological task snapshots and token/deadline/one-use rules. ChoiceKind.TASK extends the shared grammar and paged readback; DialogueCoordinator explicitly refuses task kinds so they cannot accidentally resolve a contact/file. ViewModel routes a valid captured task reply to scheduler review with expectedDueAt. The scheduler checks occurrence equality under its mutex before any state promotion. New ordinary commands invalidate task-choice/voice-choice state synchronously before waiting for older work. Other UI choices and global cancellation discard the list. The full task action is presented through normal action confirmation after list selection.

Tests cover snapshot immutability/order/filtering, exact expiry, replacement/replay, wrong choice kind, global page numbering, native stale grant rejection, second-task selection with first task untouched, no volume change from selection, and a confirmed actual volume result. Credentials and acoustic owner recognition are not injected test evidence.
